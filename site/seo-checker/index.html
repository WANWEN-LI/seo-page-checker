Page SEO & Conversion Checker

Paste a URL and get a 0–100 score plus a ranked list of fixes for technical SEO, mobile speed and conversion. Every issue says what was found, why it matters and how to fix it.

View the code on GitHub

What it checks

Technical SEO

Title, meta description, H1 and heading order, image alt text, canonical, robots, Open Graph, JSON-LD, broken links, robots.txt, sitemap.

Mobile performance

Google PageSpeed Insights: Lighthouse scores and Core Web Vitals, with real-user data when Google has it.

Content & conversion

The listing checks I used on Amazon for years: a clear offer at the top, a call to action, keyword placement, readability, and trust signals (price, reviews, delivery, contact).

How the score works

  • Each check passes (1 point), warns (0.5) or fails (0), weighted by impact (3 / 2 / 1).
  • Total = 40% Technical + 30% Performance + 30% Content & Conversion. A category that couldn't be measured is shown as N/A and left out of the total, never estimated.
  • It respects robots.txt, waits at least 1 s between requests to the same site, reads public pages only, and refuses to score bot-check or queue pages.

Built with Python (requests, BeautifulSoup), the PageSpeed Insights API, Streamlit and Jinja2, plus optional Claude suggestions. MIT licensed.
